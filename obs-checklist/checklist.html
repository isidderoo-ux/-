본방송 30분 전 테스트 점검

위에서부터 순서대로 체크 · 5단계 모두 통과하면 본방송 시작
영상 캡처카드 + 음향 믹서 → OBS → 송출 링크
확인: VU미터 사이트
T-30분
STEP 1
네트워크
통과: 업로드 ≥ 송출 비트레이트 × 1.5
  • 유선 LAN 연결 (Wi-Fi X)
  • 속도 측정
    업로드 ____ Mbps
  • 다른 기기 대용량 전송·업데이트 중지
  • 비상 회선(핫스팟) 준비
T-25분
STEP 2
영상 소스
캡처카드
통과: OBS 미리보기에 영상 정상 출력
  • 원본 장비 전원·HDMI 출력 ON
  • 캡처카드 PC 본체 포트 직결
  • 해상도·FPS가 OBS 설정과 일치
  • 다른 앱이 캡처카드 점유 X
T-20분
STEP 3
음향 소스
믹서
통과: OBS 미터 -20 ~ -10 dB, 빨간색(0 dB) X
  • 믹서 채널·마스터 뮤트 해제
  • OBS 입력 장치 = 믹서
  • 캡처카드·데스크톱 오디오 음소거 (이중 소리 방지)
  • 영상-소리 싱크 일치
T-15분
STEP 4
OBS
송출 설정
통과: 서버 URL·스트림 키 = 오늘 송출 링크
  • 송출 링크 변경·재발급 여부 확인
  • 비트레이트 ____ Kbps (CBR)
  • 키프레임 2초 · 48kHz
  • 백업 녹화 경로·용량 확인
T-10분
STEP 5
테스트 송출
VU미터 확인
통과: 사이트에서 영상 + L/R 미터 정상
  • OBS 하단 LIVE · 드롭 프레임 0%
  • 사이트 영상 끊김 없음
  • VU미터 L/R 둘 다 움직임
  • 지연 ____ 초 기록 · 5분 관찰
T-0 · 5단계 모두 통과 → 장면 전환 후 본방송 시작
문제 시
검은 화면소스 비활성화→활성화, USB 재연결
미터 무반응믹서 뮤트·OBS 입력 장치
송출 연결 실패URL·스트림 키 재확인
드롭 프레임·끊김비트레이트↓, 트래픽 중지, 비상 회선
VU미터 한쪽만믹서 출력 채널·모노/스테레오
