# 지지 않겠습니다 챌린지 봇

텔레그램 방에서 `나 OOO는 OOO에게 지지 않겠습니다` 선언을 자동으로 모아서,
**누구에게 지지 않겠다고 한 선언이 몇 %인지** 보여주는 봇입니다.

```
🔥 전체 '지지 않겠습니다' 통계 (총 3회)

1. 철수에게  ███████░░░ 66.7%  (2회, 2명)
2. 영희에게  ███░░░░░░░ 33.3%  (1회, 1명)
```

## 명령어
| 명령 | 설명 |
|---|---|
| `/stats` | 전체 기간 통계 |
| `/stats today` | 오늘(한국시간) 통계 |
| `/me` | 내 선언 기록 |
| `/reset` | 이 방 기록 초기화 (방 관리자만) |

`에게 / 한테`, `님에게`, `절대 지지 않겠습니다`, `지지않겠습니다`(붙여쓰기) 모두 인식합니다.

## 설치 방법
1. 텔레그램에서 **@BotFather** → `/newbot` 으로 봇을 만들고 토큰을 받습니다.
2. **중요:** BotFather에서 `/setprivacy` → 봇 선택 → **Disable**.
   (이걸 안 하면 봇이 방의 일반 메시지를 못 읽습니다.)
3. 봇을 챌린지 방에 초대합니다. (이미 초대했다면 privacy 변경 후 내보냈다가 다시 초대)
4. 실행:
   ```bash
   pip install -r requirements.txt
   TELEGRAM_BOT_TOKEN=발급받은토큰 python bot.py
   ```

봇은 **초대된 이후의 메시지만** 집계합니다. (텔레그램 봇은 과거 대화 기록을 읽을 수 없습니다.)
기록은 같은 폴더의 `challenge.db`(SQLite)에 저장됩니다.
