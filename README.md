# 에어컨 요청 봇

자리에서 **위치(9개 구역 + 추가 장소 3곳)**를 고르고 **🥶 추워요 / 🥵 더워요**를 누르면
담당자에게 텔레그램이나 슬랙으로 알림이 가는 웹 봇입니다.

- 설치할 패키지 없음 (Node.js 22 이상만 있으면 됨)
- 휴대폰 화면에 맞춘 UI, 앱 설치 없이 링크/QR로 접속
- 같은 구역에서 같은 요청이 연달아 들어오면 알림을 한 번만 보냄 (기본 2분)
- 구역마다 담당자를 따로 지정할 수 있음

## 실행

```bash
cp .env.example .env   # 알림 채널 설정 (아래 참고)
npm start              # http://localhost:3000
```

알림 채널을 설정하지 않으면 요청 내용이 서버 콘솔에만 찍힙니다(테스트용).

담당자에게 가는 메시지 예시:

```
🥶 [5구역] 추워요
→ 온도를 올리거나 바람을 약하게 해주세요
시간: 10. 11. 14:03
메모: 바람이 직접 와요
```

## 알림 채널 설정

### 텔레그램 (추천)

1. 텔레그램에서 `@BotFather`에게 `/newbot` 명령을 보내 봇을 만들고 **토큰**을 받습니다.
2. 담당자(또는 담당자 단톡방)가 만든 봇에게 아무 메시지나 보냅니다.
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates`를 열어 `"chat":{"id": ...}` 값을 확인합니다.
   (단톡방이면 `-`로 시작하는 숫자입니다)
4. `.env`에 입력합니다.

```
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=987654321
```

### 슬랙

슬랙 앱에서 Incoming Webhook을 만들고 URL을 `.env`에 넣습니다.

```
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...
```

둘 다 설정하면 두 곳 모두로 보냅니다.

## 구역 설정 (`config.json`)

| 항목 | 설명 |
|---|---|
| `group: "grid"` | 3×3 큰 구역 (위에서부터 1~3, 4~6, 7~9 순서로 배치) |
| `group: "extra"` | 추가 장소 (아래 줄에 표시) |
| `name` | 화면과 알림에 표시되는 이름. 실제 공간에 맞게 바꾸세요 (예: `"창가 앞"`) |
| `telegramChatId` / `slackWebhookUrl` | (선택) 이 구역만 다른 담당자에게 보낼 때 |
| `cooldownSeconds` | 같은 구역·같은 요청을 다시 알리기까지 기다리는 시간(초) |

담당자를 구역마다 나누는 예:

```json
{ "id": "X1", "name": "회의실", "group": "extra", "telegramChatId": "111111111" }
```

## 구역별 QR 코드

`http://서버주소:3000/?zone=Z3`처럼 `zone` 값을 붙이면 해당 위치가 자동으로 선택됩니다.
구역마다 이 주소로 QR 코드를 만들어 붙여 두면, 찍고 버튼만 한 번 누르면 됩니다.
한 번 고른 위치는 그 휴대폰에 기억됩니다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET` | `/api/config` | 구역 목록 |
| `POST` | `/api/request` | `{ "zoneId": "Z5", "type": "cold" \| "hot", "note": "선택" }` |
| `GET` | `/api/recent` | 최근 요청 50건 (서버 재시작 시 초기화) |
