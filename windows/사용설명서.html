QR 출석 화면 타이머 사용설명서

윈도우 PC에서 정해진 인증 시간에만 QR 화면을 보여 주고, 그 밖의 시간에는 대기화면을 띄우는 프로그램입니다.

1. 이 프로그램이 하는 일

QR 출석 화면을 띄워 둔 PC에서 다음과 같이 동작합니다.

시간화면
인증 시간 (예: 수요일 10:00 ~ 14:30)QR 화면이 그대로 보입니다.
인증 시간이 아닐 때대기화면(안내 문구, 이미지, 또는 지정한 웹사이트)이 QR 화면을 덮습니다.
  • 대기화면은 QR 화면 위에 덮어씌우는 방식입니다. 인증 시간이 되면 대기화면만 사라지고, 아래에 있던 QR 화면이 그대로 다시 보입니다.
  • 설정 창은 예약을 만들거나 바꿀 때만 열면 됩니다. 창을 닫아도 예약은 윈도우 작업 스케줄러에서 계속 동작합니다.
  • 컴퓨터를 재부팅해도 예약은 남아 있고, 로그인하면 지금 시각에 맞는 화면으로 자동으로 맞춰집니다.

2. 설치하기

  1. 받은 ScreenTimer.zip의 압축을 풉니다.
  2. 나온 ScreenTimer 폴더를 C:\ScreenTimer처럼 기억하기 쉽고 옮기지 않을 곳에 둡니다.
    예약은 이 폴더의 파일을 실행합니다. 예약을 만든 뒤에는 폴더를 옮기거나 지우지 마세요.
  3. 폴더 안의 ScreenTimer.bat을 더블클릭하면 설정 창이 열립니다.
    • "Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 누릅니다.
    • 저장할 때 권한 오류가 나면 ScreenTimer.bat을 마우스 오른쪽 클릭 → 관리자 권한으로 실행합니다.

대기화면으로 웹사이트를 띄우려면 크롬이 설치되어 있어야 합니다. 크롬이 없으면 Microsoft Edge로 띄웁니다.

3. 윈도우 설정 (꼭 해 주세요)

아래 설정을 하지 않으면 중간에 화면이 꺼지거나, QR 대신 잠금 화면이 보일 수 있습니다.

설정 위치바꿀 내용이유
설정 → 시스템 → 전원 → 화면 및 절전 "화면 끄기"와 "절전 모드"를 모두 안 함 윈도우가 알아서 화면을 끄거나 잠자기에 들어가면 예약이 동작하지 않습니다.
설정 → 계정 → 로그인 옵션 "자리를 비운 경우 언제 다시 로그인하도록 요구할까요?"를 안 함 화면이 다시 켜질 때 잠금 화면이 나오지 않게 합니다.
화면 보호기 설정 화면 보호기 없음 화면 보호기가 QR을 가리거나 잠금을 걸지 않게 합니다.
설정 → Windows 업데이트 → 고급 옵션 → 사용 시간 출석 시간을 포함하도록 지정 (예: 9:00 ~ 23:00) 출석 시간에 업데이트로 재시작되지 않게 합니다.
알림 센터 방해 금지 켜기 알림 창이 QR을 가리지 않게 합니다.
재부팅 후에는 윈도우에 로그인이 되어 있어야 예약이 동작합니다. 아무도 없을 때 재부팅될 수 있는 PC라면 자동 로그인을 설정해 두세요.

4. 예약 만들기

설정 창 왼쪽의 "새 예약" 칸에서 만듭니다.

순서  (•) 켜기 → 끄기   ( ) 끄기 → 켜기
켜기 [10:00]        끄기 [14:30]
[ ]월 [ ]화 [✓]수 [ ]목 [ ]금 [ ]토 [ ]일
끄는 시간에  (•) 안내 문구 표시  ( ) 모니터 끄기
[          + 예약 추가          ]
항목설명
순서"켜기 → 끄기"는 켜는 시각부터, "끄기 → 켜기"는 끄는 시각부터 적습니다. 어느 쪽이든 결과는 같으니 편한 쪽을 고르세요.
켜기QR 화면이 보이기 시작하는 시각 (인증 시작)
끄기대기화면이 뜨는 시각 (인증 끝)
요일먼저 실행되는 쪽 기준입니다. 두 번째 시각이 첫 번째보다 이르면 다음 날 실행됩니다. (예: 수 22:00 끄기 → 10:00 켜기 = 목요일 10시에 켜짐)
끄는 시간에안내 문구 표시: 대기화면을 띄웁니다 (보통 이걸 씁니다).
모니터 끄기: 모니터 신호만 꺼서 검은 화면이 됩니다.

"+ 예약 추가"를 누르면 바로 등록되고 아래 저장된 예약 목록에 나타납니다. 예약은 여러 개 만들 수 있습니다.

수   10:00 켜기  →  14:30 안내 문구
수   19:00 켜기  →  22:00 안내 문구

위처럼 만들면 수요일 10:00~14:30, 19:00~22:00에만 QR이 보이고, 나머지 시간(다른 요일 포함)에는 대기화면이 떠 있습니다.

  • 예약 삭제: 목록에서 예약을 클릭하고 "선택한 예약 삭제"를 누릅니다.
  • 시간 바꾸기: 기존 예약을 지우고 새로 추가합니다.
  • 지금 바로 적용: 예약 시각을 기다리지 않고, 지금 시각에 맞는 화면을 바로 띄웁니다. 예약을 처음 만든 직후에 한 번 눌러 주세요.

5. 대기화면 꾸미기

설정 창 오른쪽의 "안내 화면" 칸에서 정합니다. 바꾼 뒤에는 꼭 "저장하고 미리보기"를 눌러 주세요. 대기화면이 10초 동안 떴다가 사라집니다.

문구 / 이미지

  • 문구 표시: 화면 가운데에 보일 문구입니다. Enter로 두 줄도 쓸 수 있습니다.
  • 글자 크기: 30% ~ 300%. 너무 커도 화면 밖으로 넘치지 않게 자동으로 줄어듭니다.
  • 인증 시간 함께 표시: 문구 아래에 "인증 시간: 수 10:00 ~ 14:30"처럼 작게 표시합니다.
  • 이미지 선택: 배경으로 띄울 그림(png, jpg, bmp, gif)을 고릅니다. 16:9(예: 1920×1080) 이미지를 쓰면 화면에 꽉 찹니다. 문구도 켜 두면 이미지 위에 반투명 띠를 깔고 글자를 보여 줍니다.

웹사이트 (URL)

  • 주소를 넣으면 대기화면 대신 그 사이트를 크롬 전체 화면으로 띄웁니다.
  • 평소 쓰는 크롬과 분리된 별도 프로필로 띄우기 때문에, QR이 크롬에 떠 있어도 건드리지 않습니다. 대신 로그인 정보나 북마크는 들어 있지 않습니다.

끄기 버튼과 비밀번호

  • 끄기 버튼 표시: 대기화면 아래 가운데에 "대기화면 끄기" 버튼을 보여 줍니다.
  • 비밀번호: 입력해 두면 버튼을 누를 때 비밀번호를 물어봅니다. 출석하는 사람이 마우스를 만질 수 있다면 꼭 설정하세요.
  • 정해진 켜기 시각에는 비밀번호 없이 자동으로 사라집니다.

6. 평소 사용법

QR을 새로 고쳐야 할 때

  1. 대기화면을 닫습니다.
    방법비밀번호
    화면 아래 "대기화면 끄기" 버튼설정한 경우 필요
    Ctrl + Shift + Q (문구/이미지 화면)필요 없음
    Alt + F4 (웹사이트 화면)필요 없음
  2. QR 화면을 클릭하고 F5로 새로 고칩니다.
  3. 안내화면_다시띄우기.bat을 더블클릭해 대기화면을 다시 띄웁니다. (설정 창의 "지금 바로 적용"과 같습니다.)
    다시 띄우지 않으면 다음 끄기 시각까지 QR이 계속 보입니다. 이 파일의 바로가기를 바탕화면에 만들어 두면 편합니다.

QR 화면 띄워 두는 요령

  • 브라우저에서 F11을 눌러 전체 화면으로 띄워 둡니다.
  • 마우스 커서는 화면 구석에 둡니다.
  • 설치한 날, "저장하고 미리보기"로 대기화면이 떴다가 QR이 그대로 다시 보이는지 꼭 확인합니다.

7. 업데이트하기

  1. 새 ScreenTimer.zip의 압축을 풉니다.
  2. 안의 파일을 모두 기존 폴더(예: C:\ScreenTimer)에 덮어씁니다. 기존 예약, 문구 설정, 이미지는 그대로 남습니다.
  3. ScreenTimer.bat을 실행합니다. "예약이 다른 폴더의 파일을 실행하고 있습니다"라는 창이 뜨면 예를 누릅니다.

8. 문제가 생겼을 때

증상해결 방법
대기화면이 뜨지 않고 QR이 계속 보임 "지금 바로 적용"을 누릅니다. 예약을 처음 만든 직후나 재부팅 직후에는 다음 끄기 시각 전까지 뜨지 않을 수 있습니다.
설정과 다른 대기화면이 뜸 / 끄기 버튼이 안 보임 설정 창을 다시 열어 "예약 폴더 확인" 창이 뜨면 예를 누릅니다. 그다음 "저장하고 미리보기"로 확인합니다.
화면이 까맣게만 되고 글자가 없음 아래쪽 "모니터 끄기 테스트" 버튼은 원래 화면만 끄는 기능입니다. 대기화면 확인은 "저장하고 미리보기"로 합니다. 예약 목록 끝이 "끄기"로 되어 있다면 그 예약은 모니터 끄기 방식이니, 지우고 "안내 문구 표시"로 다시 추가합니다.
화면이 켜질 때 잠금 화면이 나옴 3. 윈도우 설정의 로그인 옵션과 화면 보호기 설정을 확인합니다.
중간에 화면이 혼자 꺼짐 전원 설정의 "화면 끄기"와 "절전 모드"가 안 함인지 확인합니다.
대기화면에 문제가 있음 프로그램 폴더에 message.log 파일이 생겼다면 그 안에 원인이 적혀 있습니다. 관리자에게 이 파일을 전달해 주세요.

9. 삭제하기

  1. 설정 창의 저장된 예약 목록에서 예약을 모두 삭제합니다.
  2. 폴더 안의 uninstall.ps1을 마우스 오른쪽 클릭 → PowerShell에서 실행합니다. 남아 있는 예약(로그인 시 확인 작업 포함)이 모두 지워집니다.
  3. 프로그램 폴더를 지웁니다.
